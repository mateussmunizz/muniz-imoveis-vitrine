# 🏢 Muniz Imóveis - Vitrine & Área do Cliente

Plataforma imobiliária moderna e de alta performance desenvolvida para revolucionar a jornada de compra, venda e locação de imóveis na Zona Norte de São Paulo. 

## 🚀 Tecnologias Utilizadas

* **Framework:** [Next.js 14](https://nextjs.org/) (App Router)
* **Estilização:** [Tailwind CSS](https://tailwindcss.com/)
* **Backend & Banco de Dados:** [Supabase](https://supabase.com/) (PostgreSQL)
* **Autenticação:** [NextAuth.js](https://next-auth.js.org/) (Google Provider)
* **Ícones:** Heroicons

## ✨ Funcionalidades

* **Catálogo Dinâmico:** Listagem de imóveis com filtros e layout responsivo de alto contraste.
* **Agendamento Inteligente:** Área logada para clientes solicitarem e acompanharem visitas aos imóveis.
* **Captação de Leads:** Formulário seguro para proprietários anunciarem seus imóveis, integrado diretamente ao CRM do painel administrativo.
* **Favoritos:** Sistema de armazenamento de imóveis favoritos por usuário.

## 🛠️ Como rodar localmente

1. Clone o repositório: `git clone https://github.com/SEU_USUARIO/muniz-imoveis-vitrine.git`
2. Instale as dependências: `npm install`
3. Crie um arquivo `.env.local` na raiz e adicione suas chaves do Supabase e NextAuth.
4. Inicie o servidor: `npm run dev`
5. Acesse `http://localhost:3000`
